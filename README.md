# 設備借用管理系統 (Equipment Borrowing Management System)

本系統是一套具備現代 RWD 響應式介面的「設備借用管理系統」，支援 Google SSO 單一簽入、卡片借用申請、個人歷史紀錄查詢，以及後端管理者審核（核准、自動庫存加扣、駁回）、設備 CRUD 管理（**動態設備類別下拉選單與即時新增類別**、**防誤刪出借中設備機制**）與管理員帳號密碼維護。後端 API 及資料庫全由 Google Apps Script (GAS) 與 Google Sheets 驅動。

---

## 📁 設備類別管理與下拉選單選擇機制

1. **「+ 新增類別」按鈕**：
   - 後台「設備庫存 CRUD 管理」頂部，新增了 **「+ 新增類別」** 按鈕，管理者可隨時點擊輸入新的設備分類名稱（如：`3D列印設備`、`VR虛擬頭盔`...）。
2. **新增/編輯設備選單**：
   - 新增或編輯設備時，「設備分類」改為**動態下拉選單 (`<select>`)**，自動列出所有現有分類。
3. **即時選單新增類別 (On-the-fly)**：
   - 下拉選單最下方設有 **`+ 即時新增新類別...`** 選項，選取後可直接輸入新類別名稱並自動帶入表單。

## 🛡️ 防誤刪保護機制 (出借中設備禁止刪除)

為避免管理者在設備尚有借用未歸還時誤刪設備資料，系統在前端與 Google Apps Script 後端皆建立了防護機制：

1. **前端雙重攔截**：
   - 當管理者在「設備庫存 CRUD 管理」點擊刪除按鈕時，系統會先檢查該設備的剩餘數量是否等於總數量（`available_qty === total_qty`），並比對該設備是否有狀態為「已出借」的紀錄。
   - 若尚有任何一件未歸還，系統會**立刻跳出紅色警告視窗（禁止刪除）**，並阻止顯示確認刪除框。
2. **後端防護 (API Level)**：
   - 即使直接透過 API 呼叫 `deleteEquipment`，Google Apps Script 後端亦會再次掃描 `Records` 工作表中是否有該設備的未歸還出借單。若有，將傳回拒絕訊息。

## 🔗 串接 Google 試算表 (Google Sheets & Apps Script 部署步驟)

### 步驟 1：建立 Google 試算表
1. 開啟 Google 試算表，建立一個全新的空白試算表，命名為「**設備借用管理資料庫**」。

### 步驟 2：寫入 Apps Script 程式碼
1. 點擊頂部選單 **「擴充功能」** ➔ **「Apps Script」**。
2. 貼上 `gas/Code.gs` 的程式碼。

### 步驟 3：初始化資料庫
1. 在 Apps Script 上方選單選擇 `setupDatabase` 函式並點擊 **「執行」**。
2. 完成後試算表將自動生成 `Equipment`、`Records`、`Admins` 三個工作表。

### 步驟 4：發布為網頁應用程式 (Web App API)
1. 點擊右上角 **「部署」** ➔ **「新增部署」** ➔ 選擇 **「網頁應用程式 (Web App)」**。
2. 誰可以存取 (Who has access)：選擇【所有人 (Anyone)】。
3. 複製生成的 Web App URL。

### 步驟 5：將 API URL 預先寫入 GitHub (實現全平台跨電腦免設定連線)
1. 開啟 `index.html` 檔案，在 `<script>` 檔頭找到 `DEFAULT_CONFIG` 常數：
```javascript
const DEFAULT_CONFIG = {
  API_URL: 'https://script.google.com/macros/s/YOUR_GAS_WEB_APP_ID/exec', // 貼上您的 Web App URL
  GOOGLE_CLIENT_ID: '' // 選填
};
```
2. 將變更儲存並 `git commit & push` 上傳至 GitHub（例如搭配 GitHub Pages 靜態網站託管）。
3. 之後不論在任何電腦、手機或瀏覽器開啟系統，皆會自動預設帶入連線，**完全無需再於網頁上手動輸入設定 API 網址**！

## ⏰ 設備借用到期提醒與逾期凍結 / 自動恢復機制

本系統具備完善的設備借到期郵件提醒與逾期權限管控機制：

1. **7 天前到期提醒 Email**：
   - 每日排程掃描，當借用紀錄距離預計歸還日期只剩 **7 天** 時，自動發送信件提醒借用者：`【EMRS 到期提醒】您借用的設備距離歸還期限只剩 1 週`。
2. **今日到期提醒 Email**：
   - 當借用紀錄預計歸還日期為**今天 (0天)** 時，發送信件提醒借用者：`【EMRS 到期提醒】您借用的設備今日到期，請於今天下班前歸還設備`。
3. **逾期凍結與登入警告**：
   - 若設備超過預計歸還日期仍未歸還（狀態為「已出借」），使用者於登入或瀏覽系統時，會**彈出警告視窗**，提示尚有設備逾期未歸還，並**暫時凍結其借用設備權限**（設備總覽按鈕顯示 `權限暫停 (尚有逾期設備)`）。
4. **自動恢復權限**：
   - 當借用者歸還設備且管理者於後台點選「**確認歸還**」後，紀錄狀態轉為「已歸還」，系統**立即自動解凍並恢復**該使用者的設備借用權限！

## 🕒 定時器觸發條件設定 (GAS Triggers)

管理者可於 Google Apps Script 主控台設定 **2 個每日排程觸發條件**：

1. **到期提醒與每日掃描**：
   - 函式名稱：**`checkBorrowReminders`**
   - 觸發條件類型：`時間驅動 (Time-driven)` ➔ `日定時器 (Day timer)` ➔ 建議設定每日上午 **08:00 - 09:00** 執行。
2. **歷史紀錄清理與 1 年逾期通知**：
   - 函式名稱：**`cleanUpOldRecords`**
   - 觸發條件類型：`時間驅動 (Time-driven)` ➔ `日定時器 (Day timer)` ➔ 建議設定每日午夜 **00:00 - 01:00** 執行。
